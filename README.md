# 匠镜

给手作人用的 iPhone 放大镜。做首饰、维修、刺绣或模型时，把手机凑近工件，放大看清楚，再把照片或视频发给客户、朋友。

界面以简体中文为主，同时提供英文。系统语言是英文时会显示英文，其他语言回退到中文。

## 功能

- 全屏后置相机预览。优先使用带超广角的虚拟摄像头（三摄或双广角），方便近距离对焦；没有时退回广角。
- 双指平滑缩放，底部滑杆，以及 1×、2×、4×、8× 快捷倍数。双击回到 1×。最大约 15 倍。
- 轻点画面对焦。
- 手电筒分关、弱、中、强四档，预览和录像时都能用。
- 应用在前台时屏幕不自动锁定。
- 拍照会截下当前放大后的画面（按屏幕上看到的比例裁切），冻结在屏幕上，保存到相册，并可以马上分享。
- 录像保存放大后的画面，可选是否录音。录完后出现分享按钮，方便发到微信等应用。
- 大按钮，主要操作都在屏幕下半部，方便单手。

## 环境

- Mac 上的 Xcode 15 或更新版本
- iPhone，系统 iOS 16 或更高
- 免费的 Apple ID 即可在自己的手机上运行（证书大约 7 天有效）

模拟器没有相机，打开后会提示没有后置相机。请用真机。

## 在真机上运行

1. 用数据线把 iPhone 连到 Mac，手机上点「信任」。
2. 双击打开 `JiangJing.xcodeproj`。
3. 左侧选中工程，再选中 **JiangJing** target，打开 **Signing & Capabilities**。
4. 勾选 **Automatically manage signing**。工程里的 Team 已设为 `G7LL8HDN83`。用这个团队的 Apple ID 登录；个人设备调试如果用不了这个团队，再临时改 Team。
5. 顶部运行目标选你的 iPhone，不要选模拟器。按 Run（▶）。
6. 若手机提示「不受信任的开发者」：打开 **设置 → 通用 → VPN 与设备管理**，信任你的开发者证书，再回到应用。
7. 第一次打开会说明为什么需要相机。点允许后，系统还会再问一次，请允许相机。录音和保存到相册会在你真正用到时再问。

Bundle ID 固定为 `com.jiangjing.magnifier`，和 Codemagic、App Store Connect 一致，不要改成别的。上传 TestFlight 的步骤见 [docs/codemagic.md](docs/codemagic.md)。

## 重新生成工程

仓库里已经带有可打开的 `JiangJing.xcodeproj`。`project.yml` 是同一份工程的描述，方便以后用 [XcodeGen](https://github.com/yonaskane/XcodeGen) 重新生成：

```bash
brew install xcodegen
xcodegen generate
open JiangJing.xcodeproj
```

新增 Swift 文件后，如果没有装 XcodeGen，也可以在 Xcode 里把文件拖进 JiangJing 分组，并勾选 JiangJing target。

## 使用时的几点

- 贴得很近、要对上细小零件时，先把倍数放回 **1×** 附近。支持近摄的 iPhone 会在这时自动切到超广角。
- 倍数拉得很高以后主要是数码放大，画面会变软，这是手机镜头的限制。
- 灯光按钮每点一次切换一档：关 → 弱光 → 中等 → 强光 → 关。手机发烫时系统可能会关掉手电筒。
- 右上角麦克风默认关闭。打开后，接下来的录像会带声音。
- 拍照会先把画面冻住。分享用系统分享面板，装了微信就可以从里面选微信。点「继续看」回到实时画面。
- 录像是完整的 16:9 画面，左右可能比手机屏幕上看到的略宽一点。照片则按屏幕上的构图裁切。

照片和视频只保存在这台手机的相册里，应用不会上传。

## 项目结构

```text
project.yml                 用 XcodeGen 重新生成工程
JiangJing.xcodeproj         可直接用 Xcode 打开
JiangJing/
  App/                      入口。前台时关闭自动锁屏
  Camera/                   采集、变焦、对焦、手电筒、拍照、录像
  Features/                 放大镜界面、按钮、分享
  Media/                    写入相册与临时文件
  Support/                  文案、变焦换算、颜色
  Resources/                图标、中英文文案
  Info.plist                相机、麦克风、添加到相册的用途说明
  PrivacyInfo.xcprivacy     隐私清单（不追踪、不收集数据）
```

## 路线图

- 对比度与滤镜：黑白、高对比、反色，方便看深色零件和线稿
- 网格或十字线，方便对齐
- 曝光锁定、对焦锁定
- 记住上次的倍数
- 可选 4K 录像
- 录像也裁成和屏幕上完全一致的画幅
- 应用内回看刚拍的内容
- 横屏

## 已知限制

- 竖屏锁定。手机平放在工件上方时，若跟着重力转画面，预览会乱转，所以固定为竖屏。
- 近摄效果取决于机型。iPhone 13 Pro 及以后的 Pro，以及带双广角的机型效果更好。只有一颗广角镜头时，仍然可以数码放大，只是最近对焦距离更远。
- 这个仓库是在没有 Xcode 的环境里写的，没有在 Mac 上实际编译，也没有在真机上点过相机、手电筒、保存和分享。请以 Xcode 编译结果为准。
