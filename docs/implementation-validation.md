# 实施与验收记录

本次在干净的隔离工作树实施批准方案的仓库内部分。没有运行 Codemagic，没有签名、上传、分发或更改外部服务。以下“已实现”描述代码变更，不代表 Mac 编译或真机验收通过。

## 已实现

- 编译问题：`CameraPreviewView.swift` 补 `SwiftUI`；畸变校正使用 Swift 属性 `isGeometricDistortionCorrectionEnabled`。
- 采集：`CaptureState` 区分空闲、照片处理、录像启动、录像、结束；主 actor 校验入口，session queue 执行硬件命令。启动期间停止意图保留至启动回调；录像开始/结束回调按文件 URL 匹配。就绪、首帧、超时、权限与设备状态回调校验代次。中断、runtime error、media services reset 撤销就绪并恢复或显示错误。短暂 inactive 禁止新采集但保持 session；进入后台再停止。
- 麦克风和灯光：用户录音偏好保留在 session queue，硬件重建尝试重新接入并发布实际结果；失败提示。KVO 同步补光灯实际可用/开启状态。变焦回调回到 session queue 校验设备；帧回调只在首帧通知 UI。
- 媒体：每次采集先建立 UUID 目录和原子 JSON 恢复记录，保存在 Application Support/PendingMedia，排除应用备份。保存结果只更新对应 ID；关闭冻结画面/横幅或采集下一段不删除文件。新增“本机媒体”，提供重试、分享、文件核验和确认丢弃；保存/分享/采集持有文件使用计数，阻止删除。已保存副本也保留至明确丢弃，须自行清理。
- 恢复：启动时恢复失败、拒绝、待保存和不完整记录；可播放视频核验通过后继续处理。中断中的相册保存标记“结果未知”，不自动重试，避免不知情地重复写入相册。强制终止前未封装完成的视频可能无法恢复；可疑文件仍保留。
- 后台：生命周期入口在排队停止录像之前申请有限后台任务；完成和到期结束任务。后台不发起首次相册授权，回到前台继续。读取明确的 `fileSizeKey`，移除宽泛文件属性读取；没有添加未经验证的 required-reason 条目。
- UI/本地化：媒体状态由对应记录展示；停止按钮不受 readiness 或音频配置禁用条件影响；不足高度时控制区可滚动。英文名称统一为 JiangJing Magnifier。新增文案均有中英文。
- 工程/CI：固定 XcodeGen 2.44.1 和官方 release SHA-256；保留工具版本、提交号和日志。无发布工作流执行逻辑测试、iOS 集成测试、Debug 模拟器及 Release 设备无签名构建，并检查产物资源。同步已提交工程的源码引用和测试 target/scheme。
- 隐私：新增应用内中英文政策及 `docs/privacy` 待发布网页。发布工作流要求真实公开 HTTPS 网址并写入发布构建 Info.plist；未部署任何页面。网页可访问性和页面标识检查不能认证政策完整性，发布主体、联系方式及 ASC 政策链接仍需发布者核对。

## Mac 与真机待验收

先只运行 `ios-simulator`，或按 README 在 Mac 生成工程与测试。检查 Debug 模拟器和 Release iphoneos 编译结果，逐条消除或解释完整并发诊断；当前仍不能承诺无并发告警。现有非 Sendable 控制器跨 GCD/Task 的捕获需要 SDK 实测诊断，未用 `@unchecked Sendable` 或关闭检查来掩盖。保留串行队列的前提是实际诊断和压力测试支持该选择。

至少在 iOS 16 和当前系统、单广角与支持近摄的机型执行以下项目，记录系统/机型/日志/输出文件。CI 使用可用的 iPhone 模拟器，不能据此声称运行过 iOS 16。

| 场景 | 期望 |
| --- | --- |
| 连续快速开始/停止、启动时立即后台 | 无卡死；停止意图兑现，输出可播放或明确失败 |
| 拍照处理中点录像、音频授权时点采集 | 控制器和 UI 均拒绝交叉操作 |
| 来电、控制中心、锁屏、前后台循环、media services reset | 就绪撤销；当前代次新帧后恢复，或明确报错；旧回调不改新状态 |
| 录音开启后重建、麦克风拒绝/接入失败 | UI 与实际输入一致；音轨符合开关 |
| 近摄、点按对焦、变焦、过热导致灯灭 | 画面/输出正确，灯光 UI 与硬件一致 |
| 照片 A 保存中继续看并拍 B、关闭后 A 保存失败 | A/B 状态独立；A 在本机媒体中可重试/分享 |
| 上一视频被拒绝/失败后再录像 | 两段都保留；旧结果不改新横幅 |
| 分享中关闭结果或打开媒体列表 | 文件占用结束前不能丢弃；分享冲突提示可重试 |
| 后台到期、首次相册权限未决定 | 没有新的后台权限弹窗；记录保留，前台继续；无后台任务泄漏 |
| 磁盘不足、损坏记录、重启 | 明确提示；不自动删除唯一副本；不能恢复的录像有核验/丢弃入口 |
| 预览 UIView 重建、分享 presenter 冲突 | 预览连接正常、手势有效；分享完成/取消正确释放文件占用 |
| SE 尺寸、最大辅助字号、VoiceOver | 停止及关键动作可访问；不遮挡或截断 |
| 重复采集/分享/重启与内存分析 | 内存无持续增长；只持有当前冻结照片/视频缩略图 |

磁盘文件保留是有意行为，长期使用会增长；应定期从本机媒体明确清理。JSON/文件写入失败仍可能令恢复状态过时，应用会提示，保留文件并将未确认的保存视为未知；这不能保证在设备断电或强制终止前最后一次写入持久化。
